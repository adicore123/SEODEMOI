# שדרוג לרמת WisePage — דפי נחיתה ממירים לכל 121 האתרים

## Context
המשתמש הפנה ל-wisepage.wwcrm.co.il/examples וביקש לקחת משם השראה: "תבין את הרמה שלנו". ניתחתי 3 דוגמאות חיות (טכנאי חשמל / שליו שיפוצים / קליניקת עיסוי) + את עמוד הדוגמאות. ה-DNA שלהם: **מכונות המרה** — יצירת קשר מיידית מכל מקום (FAB צף + כפתור טלפון ב-nav), מבנה one-pager עם nav עוגן, תגי אמון (אחריות/דירוג), מחירון, המלצות, FAQ, ווידג'ט נגישות. אנחנו חזקים בעיצוב (פונטים, אייקונים, glass, bento) אבל חסרים לנו אבני ההמרה שלהם. משלבים: מערכת העיצוב הקיימת שלנו + פטנטים שלהם. לא מעתיקים תוכן/נכסים — רק דפוסי UX.

## מה מאמצים מ-WisePage (לכל דמו)
1. **Nav עוגן sticky**: ראשי · שירותים · גלריה · המלצות · מחירון · שאלות · צור קשר + pill טלפון (היום יש לנו רק 2 כפתורים).
2. **FABs צפים**: וואטסאפ ירוק עם נקודה אדומה "1" (bottom-start) + עיגול טלפון (bottom-end) — תמיד נגישים.
3. **Hero — תג מעל הכותרת**: "★ {rating} · {reviews} ביקורות בגוגל" ב-pill (יש לנו את הנתונים האמיתיים) + **שורת מילות מפתח מתחת ל-CTA** (דפוס ה-SEO שלהם: "מספרת גברים · תספורת+זקן · ספר בעיר") + CTA שלישי שקוף "לשירותים ↓".
4. **שורת אמון מתחת ל-hero** (מחליפה את ה-strip): 3-4 pill-ים — דירוג גוגל, אחריות ואמינות, אזור שירות "{city} והסביבה", עסק פעיל.
5. **סקשן המלצות** (חדש): מספר ענק + כוכבים + "{reviews} ביקורות אמיתיות בגוגל" + פילוח כוכבים חזותי + כפתור "קראו את הביקורות בגוגל" (קישור ל-maps שכבר יש לנו). בלי ציטוטים מ up upil — רק נתונים אמיתיים.
6. **מחירון להמחשה** (חדש): 3 שורות פריט+טווח מחיר לכל קטגוריה (נתוני seo.ticket והשירותים) בכרטיס לבן מעוגל + הערת "טווחים נפוצים, תלוי בעבודה".
7. **FAQ accordion** (חדש): 4 שאלות ב-`<details>` native — תיאום, אזור שירות, אחריות, אמצעי תשלום/זמינות — עם {city} דינמי.
8. **עידון רקע**: גרדיאנט עדין cream→{chip} לאורך העמוד (הדפוס שלהם: סקשנים ככרטיסים לבנים צפים על גרדיאנט) + אורנמנט רשת-נקודות עדין בראש העמוד.
9. **שורת נגישות בפוטר** (תקן ישראלי, נוכח אצלם): "האתר מונגש... הצהרת נגישות".

## קבצים לשינוי
- **`site/assets/categories.js`** — הוספת `prices: [{item, price}×3]` ו-`faq: [{q,a}×4]` לכל 21 הקטגוריות (עם {city} דינמי בשאלות/תשובות).
- **`site/demo.html`** — nav עוגן עם לינקים, תג hero + שורת מילות מפתח + CTA שלישי, trust bar, סקשנים חדשים (המלצות #04, מחירון #05, FAQ #06, יצירת קשר #07), FABs, שורת נגישות בפוטר.
- **`site/assets/demo.css`** — nav links + underline hover, FABs (כולל pulse עדין לנקודה האדומה), trust bar pills, reviews (כוכבים גדולים + בר פילוח), price rows, details/summary styling, גרדיאנט רקע, dot-grid, מספור kickers מעודכן.
- **`site/assets/demo.js`** — רינדור המלצות מנתוני rating/reviews האמיתיים, מחירון, FAQ, FABs hrefs, מילות מפתח ב-hero, סטייט active ב-nav (IntersectionObserver), מספור kickers דינמי.
- שימוש חוזר: `window.icon()` (icons.js), מערכת reveal הקיימת, נתוני lead.rating/lead.reviews/lead.mapsUrl, seo.keywords.
